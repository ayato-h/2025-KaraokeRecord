## 概要

カラオケで歌った曲や点数を記録し、自分の成長を可視化できるWebアプリです。

単なる点数記録だけでなく、分析機能や曲管理、フレンド機能、チャット機能などを搭載し、カラオケをより楽しめることを目的として開発しました。 

## 開発背景

高校生になってから友達とカラオケに行く機会が増え、歌う曲や点数が増えていく中で、自分がどの曲を歌ったのか、どのくらい成長したのかを振り返ることが難しくなったことが開発のきっかけです。

### 課題

カラオケで歌った点数を後から忘れてしまい、

- 前回何点だったのか
- どの曲が得意なのか
- 成長しているのか

を確認できないという課題がありました。

### 解決方法

歌った曲と点数を記録し、分析・可視化することで、いつでも振り返られるアプリを作成しました。

# 主な機能

| 機能 | 概要 |
|---|---|
|  会員登録・ログイン | ユーザー登録・ログイン |
|  曲検索 | 曲名・アーティスト名から楽曲を検索 |
|  点数記録 | 歌った曲の点数やキーなどを記録 |
|  分析・可視化 | 平均点や成長推移などをグラフで表示 |
|  曲管理 | お気に入り・後で歌う曲を管理 |
|  クイズ | 音楽を聴いて曲名を当てる4択クイズ |
|  曲数計算 | 人数や利用時間から歌える曲数を計算 |
|  継続機能 | ミッション・ポイント・称号で継続をサポート |
|  フレンド | ユーザー検索・フレンド追加・ランキング |
|  チャット | フレンドとのテキスト・画像のやり取り |
|  設定 | テーマ・言語・プロフィール公開設定などを変更 |

# セットアップ

## 必要な環境

- Python 3.14
- Django 6.1.1

## 1. 仮想環境を作成

`project` ディレクトリで以下を実行します。

```bash
python3 -m venv venv
```

## 2. 仮想環境を有効化

```bash
source venv/bin/activate
```

## 3. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

## 4. Djangoサーバーを起動

```bash
cd appproject
python3 manage.py runserver
```
