## 概要

カラオケで歌った曲や点数を記録し、自分の成長を可視化できるWebアプリです。

単なる点数記録だけでなく、分析機能や曲管理、フレンド機能、チャット機能などを搭載し、カラオケをより楽しめることを目的として開発しました。 

## 開発背景

高校生になってから友達とカラオケに行く機会が増え、歌う曲や点数が増えていく中で、自分がどの曲を歌ったのか、どのくらい成長したのかを振り返ることが難しくなったことが開発のきっかけです。

### 課題

カラオケで歌った点数を後から忘れてしまい、

- 前回何点だったのか
- どの曲が得意なのか
- 成長しているのか

を確認できないという課題がありました。

### 解決方法

歌った曲と点数を記録し、分析・可視化することで、いつでも振り返られるアプリを作成しました。

# 主な機能

|---|---|
|  会員登録・ログイン | ユーザー登録・ログイン |
|  曲検索 | 曲名・アーティスト名から楽曲を検索 |

|  フレンド | ユーザー検索・フレンド追加・ランキング |
|  チャット | フレンドとのテキスト・画像のやり取り |
|  設定 | テーマ・言語・プロフィール公開設定などを変更 |

# 工夫した点

## ① データを分析・可視化

単に点数を保存するだけではなく、平均点や安定度、成長グラフを表示することで、歌唱力の変化を視覚的に確認できるようにしました。

## ② カラオケをより楽しめる補助機能

お気に入りや後で歌う機能、曲数計算機能などを実装し、カラオケ前後でも利用できるアプリを目指しました。 
## ③ 継続したくなる仕組み

ミッションやポイント制度、称号機能を実装し、ゲーム感覚で継続利用できるよう工夫しました。

<br>

# 苦労した点

開発当初は機能の実装を優先していたため、デザインや画面サイズへの対応を後から調整する形になりました。そのため、PC画面では問題なく表示できていた画面でも、スマートフォンでは要素が重なったり、ボタンや入力欄が操作しづらくなったりすることがありました。

特に、**チャット画面や機能の多いページ**では、限られた画面幅の中に多くの要素を配置する必要があり、文字サイズ・余白・ボタンの配置などを細かく調整しました。

これらの問題に対して、CSSのメディアクエリを利用して画面幅に応じてレイアウトを変更したり、要素のサイズや配置を見直したりすることで、スマートフォンでも操作しやすい画面になるよう改善しました。

また、実装する機能を考えること自体にも苦労しました。

開発を進める中で、「カラオケの記録アプリとして何があると便利か」を考えながら新しい機能を追加していったため、途中でアイデアが増え、どの機能を実装するか迷うこともありました。

その結果、点数記録や分析だけでなく、クイズ、曲数計算、履歴、フレンド、チャットなど、さまざまな機能を追加しました。

一方で、機能を増やすことを優先したことで、後からUIや画面構成を調整する必要が生じました。この経験から、**機能を実装する前に、アプリ全体の構成やユーザーの操作の流れを考えておくことの重要性**を学びました。

<br>

# 今後改善したい点

本アプリの開発を通して、機能を追加することだけでなく、**ユーザーが迷わず操作できるUI設計と、それを支えるアプリ全体の設計が重要である**と実感しました。

開発当初はアイデアを形にすることを優先したため、制作途中で新しい機能を追加することも多く、結果として機能数は増えた一方で、操作性や画面構成には改善の余地があると感じています。

今後は、アプリの根幹となる設計をより明確にした上で、機能を追加していくことを意識し、**「何ができるか」だけでなく「どうすれば迷わず使えるか」**を重視したUI・UXの改善に取り組みたいです。

具体的には、以下の機能・改善を検討しています。

- **UI・UXの改善**
  - 画面構成や導線を見直し、直感的に操作できるUIを目指す
  - 機能追加によって複雑になった操作を整理する
  - アプリ全体で統一感のあるデザイン・ナビゲーションを設計する
- **おすすめ曲機能**
  - ユーザーの記録や好みに応じて、おすすめの曲を提示する機能
- **通知機能**
  - 新しいおすすめ曲やフレンドからのアクションなどを通知する機能
- **設計・保守性の改善**
  - 機能追加を前提とした構造を見直し、今後の拡張や変更を行いやすくする
- **テストコードの追加**
  - 主要な機能に対するテストを整備し、機能追加による不具合を防ぐ

# セットアップ

## 必要な環境

- Python 3.14
- Django 6.1.1

## 1. 仮想環境を作成

`project` ディレクトリで以下を実行します。

```bash
python3 -m venv venv
```

## 2. 仮想環境を有効化

```bash
source venv/bin/activate
```

## 3. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

## 4. Djangoサーバーを起動

```bash
cd appproject
python3 manage.py runserver
```
